# Portfolio Case Study

## Title
AI-Powered Identity Operations & JML Automation Platform

## Problem
Manual IAM operations can create inconsistent access decisions, excessive
entitlements and slow JML processing.

## Solution
A controlled identity-security workflow combining Entra context, Graph API,
policy-based access decisions, AI-assisted analysis and human-approved
automation.

## Engineering highlights
- Deterministic authorization boundary
- AI advisory layer
- Identity/risk/access analysis
- JML lifecycle workflows
- Graph integration
- PowerShell automation
- Fail-closed policy behavior
- Automated testing
- Audit-ready JSON evidence

## Outcome
Demonstrates identity-security engineering rather than simple Entra
administration.

## Demo story
1. Submit Finance access request.
2. Retrieve identity context.
3. Analyze current access.
4. Generate AI recommendation.
5. Validate against policy.
6. Approve/review/block.
7. Show controlled execution state.
8. Show evidence report.

## Resume bullet candidates

- Designed an AI-assisted identity operations platform integrating Microsoft
  Entra ID concepts, Graph API, deterministic IAM policy controls and
  human-in-the-loop approval for access and JML workflows.
- Built policy/risk engines to identify department-entitlement mismatches,
  excessive access and privileged requests using fail-closed security logic.
- Automated identity-analysis workflows using Python, PowerShell and structured
  JSON outputs with audit-ready evidence and repeatable test scenarios.
